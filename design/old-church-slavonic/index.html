Old Church Slavonic

Старокириллическая

A keyboard layout for typing the old Cyrillic letters, from ѧ to ѡ.

Простой способ набирать буквы кириллицы от ѧ до ѡ.

Why

Зачем нужна эта раскладка

As a philologist, I keep running into texts where the old Cyrillic letters are pasted in as pictures, typed in special fonts like Izhitsa so that they can’t be copied, or replaced with wrong characters — “ѣ” turned into “љ”, for example.

Я филолог и часто сталкиваюсь с текстами, в которых старые буквы кириллического алфавита либо вставлены как картинки, либо набраны специальными шрифтами вроде Ижицы (то есть их нельзя скопировать), либо заменены неправильными знаками — например, «ѣ» заменяют на «љ».

Yet the most used old Cyrillic letters are in Unicode and in ordinary system fonts — few people seem to know it: Ѹ Ѯ Є Ѥ Ѕ Ѳ Ѱ Ѣ Ѡ Ѧ Ѩ Ѵ Ѿ Ѻ Ѫ Ѭ. That line is plain text: try copying it.

А самые используемые старые кириллические символы есть в Юникоде и системных шрифтах — видимо, об этом мало кто знает: Ѹ Ѯ Є Ѥ Ѕ Ѳ Ѱ Ѣ Ѡ Ѧ Ѩ Ѵ Ѿ Ѻ Ѫ Ѭ. Это обычный текст — попробуйте его скопировать.

How it works

Как она работает

Install it, make it the active layout and type. Save the layout scheme for yourself.

Установите, выберите как активную раскладку и печатайте. Сохраните себе схему расположения символов.

How to install

Как установить

На macOS: откройте образ и перетащите файл раскладки на ярлык папки Keyboard Layouts рядом с ним. Потом добавьте раскладку в Системных настройках → Клавиатура → Источники ввода.

On macOS, open the disk image and drag the layout file onto the Keyboard Layouts shortcut next to it. Then add the layout in System Settings → Keyboard → Input Sources.

На Windows: распакуйте архив и запустите setup.exe.

On Windows, unzip the archive and run setup.exe.

The layout is inspired by Ilya Birman’s Typographic Layout. If all you need is ѣ, ѵ, і and ѳ, use that one instead.

Раскладка вдохновлена Типографской раскладкой Ильи Бирмана. Если вам нужно набирать только ѣ, ѵ, і и ѳ — лучше воспользуйтесь ей.
